Стыковка: Перемещение в `03_Игровой_цикл.md`, выживание в `08_Выживание.md`, расы / создание персонажа в `05_Расы.md` и `04_Создание_персонажа.md`.

---

## Перемещение

- 1 действие **Перемещение** = **1 гекс**.
- Стоимость: **2 ОД** (платит тот, кто идёт). Тип местности цену ОД **не** меняет.
- Следопыт в нише расы — раз за рывок **1 ОД** вместо 2 (`04_Создание_персонажа.md`).
- Персонажи могут стоять на **разных** гексах; каждый платит за свой ход.
- Держаться вместе **выгоднее**: классовые бонусы, общий лагерь, меньше риска остаться одному.

В **Лагере** обычный маршрут по карте за ОД недоступен — сначала свернуть лагерь.

## Туман войны и видимость

| Откуда смотрит | Что знает |
|----------------|-----------|
| Гекс **под ногами** | **Тип** + **детали** локации (ключ сценария) |
| **Соседний** гекс | Только **тип** |
| Дальше | Туман |

Стоя на гексе, герой видит **типы всех соседних** гексов.

**Разведчик:** раз за рывок (бонус класса) с соседнего гекса мастер даёт **одну деталь** содержания этого гекса — не полный ключ.

## Типы местности

Жетоны на столе (6 типов):

| Тип | На столе | Давление выживания |
|-----|----------|-------------------|
| **Лес** | Иконка леса | Без автоштрафа; триггер по сцене |
| **Равнины / поселения** | Равнина, дымы | Без автоштрафа; триггер по сцене |
| **Горы** | Пики | +1 **Силы** только если переход объявлен **долгим/тяжёлым** |
| **Пещеры** | Подземелье | Без автоштрафа; триггер по сцене (тьма, обвал…) |
| **Берег / море** | Берег или вода | Берег — как сцена; **открытое море** при ходе: +1 **Тело** или **Дух**; обычно **непроходимо** без сюжета |
| **Вулкан / пепел** | Лава, пепел | При входе: +1 **Тело** или **Силы** (по сцене/мастеру) |

## Границы и раскладки

- На столе одновременно — **одна раскладка региона** (порядка десятков гексов текущего края), не весь мир.
- Край раскладки + непроходимые типы (**открытое море**, **стена гор**, **пепел** без сюжета) = граница **этого** региона.
- Переход в другой край мира: **новая раскладка** (старую убрать). Между раскладками — сцена перехода (корабль, перевал, тоннель): ОД / лагерь / риск, без гексов «через весь океан».
- Сюжетный проход через «непроходимое» открывает мастер.

## Расовые ниши (`#раса_исследование`)

| Раса | Своя ниша (типы) |
|------|------------------|
| **Эльф** | Лес; в сценарии также дикая поверхность |
| **Гном** | Пещеры |
| **Орк** | Вулкан / пепел; спорные края по ключу |
| **Человек** | Нет узкой ниши — везде средне |

**В своей нише**, раз за рывок: можно **не** получить +1 **Силы** от объявленного долгого/тяжёлого перехода.  
**В чужой нише:** мастер чаще давит средой (не автоштраф на каждый гекс).  
Следопыт дополнительно удешевляет одно Перемещение в нише (см. класс).

## Что на столе (физика)

- Сетка / раскладка гексов текущего региона.
- Жетоны **типа** местности.
- Жетоны **персонажей**.
- По желанию маркер «уже были».

**Не** используем общую колоду «содержание леса» на все партии.

---

## Что у мастера (содержание)

- **Ключ сценария:** гекс → название, вход, опасности, NPC, связи, последствия повторного визита.
- Уникальные места (лес эльфов, город гномов, пещеры орков, поселения людей…) — проработанные локации.
- Другая партия / прогон — другой ключ или те же места с другими событиями.
- Опционально позже: малая колода случайных встреч только для «серых» дорожных гексов.

Связка с концепт-картой: `04_Art/World` — ориентир зон; координаты в ключе сценария.

## Процедура входа в гекс

1. Тип (если ещё не виден ореолом).
2. Описание под ногами по ключу.
3. Событие / выбор / Взаимодействие / Бой — если есть.
4. Давление типа и ниши — по таблицам выше + `08_Выживание.md`.

## Принципы

1. Исследование важнее боя.  
2. Разойтись можно; вместе — умнее.  
3. Стол: **где** и **тип**; **что** — у сценария.  
4. Реиграбельность — через локации и последствия.  
5. Мир имеет края региона; весь мир не обязан лежать на столе сразу.
