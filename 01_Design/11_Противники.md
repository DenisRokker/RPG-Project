# Противники

Роли, пулы и уникалки врагов. Язык боя (обмен, раны, верх/вниз) — в `07_Боевая_система.md`.  
Этот файл можно наращивать и править **обособленно** от свода боя.

Баланс стычек — под **3 героя** (1 удар + 2 реакции). Прогоны — `03_Campaigns/Прогоны_боя.md`.

---

## Связь с боем

| В `07` | Здесь |
|--------|--------|
| Обмен, карты партии, раны, темп | Роль на столе, пул намерений, поведение |
| Уникальные героев (сброс) | Классовые / расовые / сценические врага |
| Шаблон врага (кратко) | Полные роли и (позже) экземпляры |

За обмен враг-ведущий или ключевой кладёт **одну** карту.  
**Не больше одной уникальной** за обмен (класс / раса / сцена / отчаянный — выбрать одну).

## Роли

### 1. Ведущий стычки

Обычный «главный» сцены: **1 намерение за обмен**, полная рука.

| Поле | Основа |
|------|--------|
| Лестница | целый → ранен → тяжело → выбит |
| В обмене | 1 карта из пула |
| Уникалка | **Классовая** (1): после игры → сброс, обычно **до конца боя** |
| Поведение | открытый → мешающий → лекарь; цель не меняет без причины |
| Засада | он застал → партия **открыта**; вы его → он с **вниз** |
| При тяжело | режим **Отчаянный** (см. ниже) |

**Примеры слотов:** охотник-орк, старший дозора.

#### Пул ведущего (база)

| Намерение | Тип | Суть |
|-----------|-----|------|
| **Удар** | база | Прямая атака |
| **Натиск** | база | Сближение + удар; сильнее по **открытым** |
| **Блок** | база | Срыв / 0 ступени чужому удару |
| **Отход** | база | Снять давление; сбить **верх** партии, если уместно |
| **Выбрать слабого** | база | Раненый / лекарь / без прикрытия |
| **Классовая** | уникалка | Боевое выражение класса (см. ниже) |
| **Отчаянный натиск** | отчаянный | Только в режиме Отчаянный: макс. удар, сам **открыт** |

Базовое после розыгрыша — обратно в руку. Классовая и отчаянный — по правилам сброса / режима.

---

### 2. Давление

Второй план: **своей карты нет**, пока сценарий не отдаст темп.

| Поле | Основа |
|------|--------|
| Лестница | та же или короче; чаще снимается ударом/помощью, не дуэлью карт |
| В обмене | жетон угрозы (ниже) |
| Уникалка | нет |
| Карта | если ведущий выбит / «отдал темп» / подмога / затяжка → на 1 обмен урезанный пул: удар · отход |

**Примеры слотов:** ножевик, рядовой дозора, подручный мага.

#### Жетоны давления

| Жетон | Суть |
|-------|------|
| **Угроза фланга** | Нет прикрытия / сбития → в конце обмена **+1 ступень** или **открыт** на вторую цель (по поведению) |
| **Мешает строю** | Удар партии по ведущему без помощи/прикрытия — слабее или без усиления |
| **Целится в спину** | Приоритет: лекарь / открытый сзади |

---

### 3. Ключевой

Кульминация: тот же язык обменов; **смена поведения после «тяжело»**; часто **малое поле**.

| Поле | Основа |
|------|--------|
| Лестница | та же; после **тяжело** — другие приоритеты, не «просто сильнее» |
| В обмене | 1 карта |
| Уникалки | **Расовая** (1, до конца боя) + **уникалка сцены** (по сценарию; часто 1 раз / до Лагеря) |
| Поведение | дистанция / позиция; уникалка сцены страшная, с ценой для себя |
| При тяжело | режим **Отчаянный**; чаще отход / обман / уникалка, реже честный удар в лоб |

**Пример слота:** Искрящийся.

#### Пул ключевого (база)

| Намерение | Тип | Суть |
|-----------|-----|------|
| **Удар** | база | Оружие / импульс — обычная ступень |
| **Обман** | база | Сбить чужое намерение или сменить цель давления |
| **Отход за позицию** | база | Укрытие / край поля; готовит уникалку сцены |
| **Сбить темп** | база | **Вниз** / страх; сбить **верх** героя |
| **Расовая** | уникалка | Боевое выражение расы (см. ниже) |
| **Уникалка сцены** | уникалка | Сценарийная угроза (у мага — **вспышка**) |
| **Отчаянная угроза** | отчаянный | Уникалка сцены на максимуме; сам максимально уязвим |

---

### 4. Режим «Отчаянный»

Не отдельная карточка бестиария — **режим** ведущего или ключевого.

| Поле | Правило |
|------|---------|
| Триггер | **тяжело**, или метка сценария |
| Что кладёт | отчаянная карта **вместо** обычной |
| Эффект | максимальный удар / угроза; сам **открыт** (или эквивалент сцены) |
| Лимит | одна уникалка за обмен — отчаянный **или** класс/раса/сцена, не две сразу |
| Смысл | последний клык, не вторая жизнь |

## Боевые уникалки: класс и раса

Классовые бонусы героев в `04` и расы в `05` в основном **вне боя**. Здесь — **боевые выражения** той же фантазии для врагов (черновик для баланса).

### Классовые (ведущий)

| Класс | Боевая карта (черновик) | Суть |
|-------|-------------------------|------|
| **Следопыт** | Меткий / замедляющий выстрел | Ступень + **вниз** или помеха на отход цели |
| **Воин** | Жёсткий ответ | Блок с контрударом / стянуть огонь на себя с усилением |
| **Лекарь** | Грязный приём | Себе −давление **или** яд/**кровотечение** на цель |
| **Разведчик** | Из слепой зоны | Удар с фланга; цель **открыта**, если не было реакции на фланг |
| **Шаман** | Знамение / страх | **Вниз** или срыв намерения Волей/Духом |
| **Носитель** | Малая вспышка | Слабее ключевой сценической; сам рискует / **открыт** |

### Расовые (ключевой)

| Раса | Боевая карта (черновик) | Суть |
|------|-------------------------|------|
| **Эльф** | Лесная линия | Отход без потери темпа / удар из укрытия с преимуществом |
| **Человек** | Удачный трюк | Раз за бой переиграть своё намерение после переворота **или** игнор одного усиления партии |
| **Гном** | Камень под ногами | Не сбить с позиции; блок сильнее на малом поле / в укрытии |
| **Орк** | Испытание | Не снимает **вниз** отходом — вместо этого бьёт сильнее; или игнор страха/сбития темпа раз за бой |

Детали чисел и формулировок — после прогонов с партией.

## Шаблон экземпляра (на потом)

1. Имя.  
2. Роль (ведущий / давление / ключевой).  
3. Раса · класс (если ведущий или ключевой).  
4. Лестница ран.  
5. Пул = база роли + выбранная уникалка(+и).  
6. Поведение и жетоны давления (если есть союзники-давление).  
7. Засада / малое поле / метки сценария.

## Принципы файла

1. Роль важнее имени.  
2. Давление дёшево и читаемо.  
3. Ведущий показывает **класс**, ключевой — **расу** (+ сцену).  
4. Одна уникалка за обмен.  
5. Отчаянный — финал, не рефилл.  
6. Экземпляры правятся здесь; язык обменов — только в `07`.
